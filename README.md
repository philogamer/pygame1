this is a game that I make by pygame
the character move by using WASD and normal attack by left arrow and right arrow
each time player move or attack will cost mana 
the less mana the slower speed of the player
kill enemy and boss increase the player experience
each time player level increase(cost an amout of experience) there is 2 buff for player to choose to buff each stat of the character
each time a group of enemy born I call it a wave, each 12 wave player need to combat with the boss
on standard maps, main character can exit through paths other than the one they entered by whenever you want
on boss map, player can't exit unless killed the boss
through each wave the stats off the enemy and boss grow up
get into the new map, the map shape and structure will change randomly
get into a new map, the mana fully regen
if the bullet touch walls it will be disappear, both the enemy and player can't go through walls
the enemy will float randomly until saw the player in its view and start chasing the player
the enemy will keep range and shoot the bullet to the player
Try to last as long as you can, end game will give the record of your play
