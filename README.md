# LOST SOUL

A dungeon game made with pygame: do anything to survive and the game will show reward at the end.

## HOW THIS WAS MADE
this project was made with pygame

## code structure
- **main.py**: the main loop
- **information.py**: store class, variables and texts that will draw on screen
- **function.py**: the logic after each events
- **dictionary.py**: the events in game

## special features
- random map
- simple AI enemy
- in-game guides

## run?
- choose a **release**
- download the zip or rar file
- open dist folder
- open .exe file and play

## AI DISCLOSURE
I used AI to help balance the stats and the math around them, such as how enemy first stats and increase scale with waves, player stats, mana costs, and passive skill values.
